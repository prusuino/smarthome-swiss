AK MODUL-BUS RD30 contact inputs over a serial device server

Kontakteingänge des AK MODUL-BUS RD30 über einen seriellen Geräteserver

Entrées de contact AK MODUL-BUS RD30 via un serveur série

Ingressi di contatto AK MODUL-BUS RD30 tramite server seriale

The 30 digital contact inputs of an AK MODUL-BUS RD30 module as binary sensors — event-driven over a serial device server such as a Moxa NPort. Name the inputs and pick device classes in the UI; door contacts, water sensors, alarm panel outputs or pump status land directly in Home Assistant. Requires a serial-to-Ethernet device server — the RD30 alone has only an RS-232 port.

Die 30 digitalen Kontakteingänge eines AK MODUL-BUS RD30 als Binärsensoren — ereignisgesteuert über einen seriellen Geräteserver wie den Moxa NPort. Eingänge in der Oberfläche benennen und mit Geräteklasse versehen; Türkontakte, Wassermelder, Ausgänge der Alarmanlage oder Pumpenstatus landen direkt in Home Assistant. Setzt einen Seriell-zu-Ethernet-Geräteserver voraus — der RD30 allein hat nur eine RS-232-Schnittstelle.

Les 30 entrées de contact numériques d'un module AK MODUL-BUS RD30 comme capteurs binaires — pilotés par événements via un serveur de port série tel que le Moxa NPort. Nommez les entrées et choisissez les classes d'appareil dans l'interface ; contacts de porte, détecteurs d'eau, sorties de centrale d'alarme ou état de pompe arrivent directement dans Home Assistant. Nécessite un serveur série-Ethernet — le RD30 seul n'a qu'un port RS-232.

I 30 ingressi a contatto digitali di un modulo AK MODUL-BUS RD30 come sensori binari — gestiti a eventi tramite un server seriale come il Moxa NPort. Assegna nomi e classi di dispositivo agli ingressi dall'interfaccia; contatti porta, rilevatori d'acqua, uscite della centrale d'allarme o stato pompa arrivano direttamente in Home Assistant. Richiede un server seriale-Ethernet — il solo RD30 dispone unicamente di una porta RS-232.

How to install

Installation

Installation

Installazione

Click Add to Marketplace to add the repository to the Home Assistant Marketplace (formerly HACS), download it and restart Home Assistant. Then add the integration under Settings → Devices & services. Free and open source, no account needed. The full documentation is in the README on GitHub.

Klicke auf Zum Marketplace hinzufügen, um das Repository zum Home Assistant Marketplace (früher HACS) hinzuzufügen, lade es herunter und starte Home Assistant neu. Füge die Integration danach unter Einstellungen → Geräte & Dienste hinzu. Kostenlos und quelloffen, kein Konto nötig. Die ganze Dokumentation steht im README auf GitHub (englisch).

Cliquez sur Ajouter au Marketplace pour ajouter le dépôt au Marketplace de Home Assistant (anciennement HACS), téléchargez-le et redémarrez Home Assistant. Ajoutez ensuite l'intégration sous Paramètres → Appareils et services. Gratuit et open source, sans compte. La documentation complète se trouve dans le README sur GitHub (en anglais).

Fai clic su Aggiungi al Marketplace per aggiungere il repository al Marketplace di Home Assistant (ex HACS), scaricalo e riavvia Home Assistant. Aggiungi poi l'integrazione in Impostazioni → Dispositivi e servizi. Gratuito e open source, nessun account necessario. La documentazione completa è nel README su GitHub (in inglese).
