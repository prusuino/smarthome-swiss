Controllo locale dell'Innoxel Master 2 tramite un server seriale

Local control of an Innoxel Master 2 (NOXmaster) through a serial device server such as a Moxa NPort — switches, lights, dimmers, blinds and the weather station. Home Assistant presses the keys programmed in INNOXEL Setup and reads the real state of the outputs back. Requires a serial-to-Ethernet device server — the Master 2 has only an RS-232 port.

Lokale Steuerung eines Innoxel Master 2 (NOXmaster) über einen seriellen Geräteserver wie den Moxa NPort — Schalter, Lichter, Dimmer, Storen und die Wetterstation. Home Assistant drückt die in INNOXEL Setup programmierten Tasten und liest den echten Zustand der Ausgänge zurück. Benötigt einen Seriell-zu-Ethernet-Geräteserver — der Master 2 hat nur einen RS-232-Anschluss.

Commande locale d'un Innoxel Master 2 (NOXmaster) via un serveur de port série tel que le Moxa NPort — interrupteurs, éclairages, variateurs, stores et station météo. Home Assistant actionne les touches programmées dans INNOXEL Setup et relit l'état réel des sorties. Nécessite un serveur de port série vers Ethernet — le Master 2 ne dispose que d'un port RS-232.

Controllo locale di un Innoxel Master 2 (NOXmaster) tramite un server seriale come il Moxa NPort — interruttori, luci, dimmer, tapparelle e stazione meteo. Home Assistant preme i tasti programmati in INNOXEL Setup e rilegge lo stato reale delle uscite. Richiede un server da seriale a Ethernet — il Master 2 ha solo una porta RS-232.

Highlights

Das kann die Integration

Points forts

Punti di forza

Diese Liste gibt es nur auf Englisch.

Cette liste n'existe qu'en anglais.

Questo elenco è disponibile solo in inglese.

  • Local and direct: talks the serial protocol of the master through a serial device server on your own network — no cloud, no extra gateway software.
  • Works like a wall button: Home Assistant presses the keys you programmed in INNOXEL Setup and reads the real state of the outputs back.
  • Switches and lights with true state: a command only presses the key when the output is in the other state, so two automations never cancel each other out.
  • Blinds: one key impulse runs a blind to its end position, an impulse while it moves stops it.
  • Outputs found for you: leave the output address empty and the integration detects which output a key switches.
  • Weather station: temperature, wind speed, sun brightness east/south/west, twilight and rain appear on their own when a weather station is connected.
  • Long key presses: the send_key action sends an impulse, or press and release separately.
  • INNOXEL Setup stays usable: one switch releases the connection to the device server while you reprogram the master.

How to install

Installation

Installation

Installazione

Click Add to Marketplace to add the repository to the Home Assistant Marketplace (formerly HACS), download it and restart Home Assistant. Then add the integration under Settings → Devices & services. Free and open source, no account needed. The full documentation is in the README on GitHub.

Klicke auf Zum Marketplace hinzufügen, um das Repository zum Home Assistant Marketplace (früher HACS) hinzuzufügen, lade es herunter und starte Home Assistant neu. Füge die Integration danach unter Einstellungen → Geräte & Dienste hinzu. Kostenlos und quelloffen, kein Konto nötig. Die ganze Dokumentation steht im README auf GitHub (englisch).

Cliquez sur Ajouter au Marketplace pour ajouter le dépôt au Marketplace de Home Assistant (anciennement HACS), téléchargez-le et redémarrez Home Assistant. Ajoutez ensuite l'intégration sous Paramètres → Appareils et services. Gratuit et open source, sans compte. La documentation complète se trouve dans le README sur GitHub (en anglais).

Fai clic su Aggiungi al Marketplace per aggiungere il repository al Marketplace di Home Assistant (ex HACS), scaricalo e riavvia Home Assistant. Aggiungi poi l'integrazione in Impostazioni → Dispositivi e servizi. Gratuito e open source, nessun account necessario. La documentazione completa è nel README su GitHub (in inglese).
