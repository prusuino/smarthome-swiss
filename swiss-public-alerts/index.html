Alertes Alertswiss et dangers naturels

Allerte Alertswiss e pericoli naturali

Official Swiss public alerts (Alertswiss) in Home Assistant: knows whether an alert polygon actually covers your home, shows map markers and ships a ticker, list and detail card plus a dashboard strategy that builds the whole view in the browser. Optionally adds the natural hazard danger levels (naturgefahren.ch) for your postal code — one sensor per hazard process, from thunderstorms to forest fires.

Offizielle Schweizer Behördenwarnungen (Alertswiss) in Home Assistant: erkennt, ob ein Warnpolygon dein Zuhause wirklich betrifft, zeigt Karten-Marker und bringt Ticker-, Listen- und Detail-Karte plus eine Dashboard-Strategie mit, die die ganze Ansicht im Browser aufbaut. Optional dazu: die Naturgefahren-Gefahrenstufen (naturgefahren.ch) für deine Postleitzahl — ein Sensor pro Gefahrenprozess, von Gewitter bis Waldbrand.

Alertes officielles suisses (Alertswiss) dans Home Assistant : détecte si un polygone d'alerte couvre réellement votre domicile, affiche des marqueurs sur la carte et fournit des cartes ticker, liste et détail plus une stratégie de tableau de bord qui construit toute la vue dans le navigateur. En option : les degrés de danger naturel (dangers-naturels.ch) pour votre code postal — un capteur par processus de danger, de l'orage à l'incendie de forêt.

Allerte ufficiali svizzere (Alertswiss) in Home Assistant: rileva se un poligono di allerta copre davvero la tua casa, mostra marcatori sulla mappa e include card ticker, elenco e dettaglio più una strategia di dashboard che costruisce l'intera vista nel browser. In opzione: i gradi di pericolo naturale (pericoli-naturali.ch) per il tuo codice postale — un sensore per ogni processo di pericolo, dal temporale all'incendio di bosco.

Highlights

Das kann die Integration

Points forts

Punti di forza

Diese Liste gibt es nur auf Englisch.

Cette liste n'existe qu'en anglais.

Questo elenco è disponibile solo in inglese.

  • Knows whether your home is affected: your home location is tested against the official area polygon of every alert — not a radius guess.
  • The full official text: alert text and behaviour instructions on the sensor; test alerts and all-clear messages are filtered out.
  • Alerts on the map and in numbers: one marker per alert with a severity symbol, the number of alerts nationwide and for your home.
  • Natural hazard danger levels: optionally the levels from naturgefahren.ch for twelve processes — from wind, thunderstorm and heat wave to flood, avalanches and forest fire — with a sensor for the highest one.
  • Three dashboard cards: ticker, alert and list, filtered by canton, distance or severity, all with a visual editor — plus a dashboard strategy.
  • Built for the automation editor: triggers (alert for the home location started, cleared, alert count increased), conditions (home location is / is not affected) and a notification blueprint — no templates needed.
  • Set up in a minute: pick the sources, the language and the minimum severity; German, English, French and Italian; diagnostics download with your coordinates redacted.

How to install

Installation

Installation

Installazione

Open Settings → Marketplace in Home Assistant, search for Swiss Public Alerts and download it. Restart Home Assistant, then add the integration under Settings → Devices & services. Free and open source, no account needed. The full documentation is in the README on GitHub.

Öffne in Home Assistant Einstellungen → Marketplace, suche nach Swiss Public Alerts und lade die Integration herunter. Starte Home Assistant neu und füge sie unter Einstellungen → Geräte & Dienste hinzu. Kostenlos und quelloffen, kein Konto nötig. Die ganze Dokumentation steht im README auf GitHub (englisch).

Ouvrez Paramètres → Marketplace dans Home Assistant, cherchez Swiss Public Alerts et téléchargez l'intégration. Redémarrez Home Assistant, puis ajoutez-la sous Paramètres → Appareils et services. Gratuit et open source, sans compte. La documentation complète se trouve dans le README sur GitHub (en anglais).

Apri Impostazioni → Marketplace in Home Assistant, cerca Swiss Public Alerts e scarica l'integrazione. Riavvia Home Assistant, poi aggiungila in Impostazioni → Dispositivi e servizi. Gratuito e open source, nessun account necessario. La documentazione completa è nel README su GitHub (in inglese).
