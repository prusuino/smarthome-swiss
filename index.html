Environment & Safety

Live data from Switzerland's official environmental and civil-protection services.

Swiss Meteo

v1.5.4In Marketplace default catalogMeteoSwiss Open DataRadarWarningsDashboard cards

The MeteoSwiss local forecast for your place (nine days, hour by hour, with the uncertainty range), the live values of the nearest SwissMetNet station, the official warnings matched to your point, pollen counts with the MeteoSwiss load classes and the station's history back to 1980 and the precipitation radar as a loop around your place on the swisstopo map, with a motion-based estimate for the next hour — all from open data, read sparingly. Triggers and conditions for the automation editor, heating-degree-day and solar figures, and five dashboard cards in three colour schemes.

Data: Federal Office of Meteorology and Climatology MeteoSwiss (open data, CC BY 4.0); warnings via MeteoAlarm (EUMETNET)

Swiss Waters

v1.8.1In Marketplace default catalogFOEN / BAFUBadestellen

Live water temperature, water level, discharge and flood danger levels for Swiss rivers and lakes from the official hydrological monitoring network. Set up all stations within a radius or pick a single favourite. Also covers the official bathing sites: bathing water quality per the EU Bathing Water Directive and the live bathing water temperature of the Zurich lake stations.

Data: Federal Office for the Environment (FOEN/BAFU) via LINDAS
GitHub Add to Marketplace

Swiss Public Alerts

v1.7.2In Marketplace default catalogAlertswissnaturgefahren.ch

Official Swiss public alerts (Alertswiss) in Home Assistant: knows whether an alert polygon actually covers your home, shows map markers and ships a ticker, list and detail card plus a dashboard strategy that builds the whole view in the browser. Optionally adds the natural hazard danger levels (naturgefahren.ch) for your postal code — one sensor per hazard process, from thunderstorms to forest fires.

Data: Federal Office for Civil Protection (Alertswiss) · Natural Hazards Portal of the Confederation
GitHub Add to Marketplace

Swiss Avalanche Bulletin

v1.6.1In Marketplace default catalogSLFIMIS

The official Swiss avalanche bulletin for your location: danger level, aspect and elevation information with proper EAWS terminology in four languages. Supports multiple locations — home, ski resort, tour region. Now also with IMIS measuring stations as favourites: snow depth, temperatures and wind from ~200 high-alpine stations, with a bundled station card.

Data: WSL Institute for Snow and Avalanche Research SLF (CC BY 4.0)
GitHub Add to Marketplace

Swiss Earthquakes

v1.9.2In Marketplace default catalogSED

Recent Swiss earthquakes on Home Assistant's built-in map, with an overview sensor (location · magnitude · date) and a human-readable magnitude scale in four languages.

Data: Swiss Seismological Service (SED) at ETH Zurich
GitHub Add to Marketplace

Swiss Hail Protection

v1.6.0In Marketplace default catalogVKFMeteoSwiss

Swiss hail warnings for your blinds: either the official VKF hail-protection signal («Hagelschutz – einfach automatisch», for buildings registered with the cantonal building insurers, about 20 minutes ahead) or the MeteoSwiss hail radar — probability of hail and expected hail size around your location, open data, no registration. Both deliver the same alarm sensor for your automations.

Data: VKF / NetITServices hail-warning service · MeteoSwiss hail radar products (Open Data)
GitHub Add to Marketplace

GitHub Add to Marketplace

RD30 Digital Interface

v1.0.1AK MODUL-BUSMoxa NPort

The 30 digital contact inputs of an AK MODUL-BUS RD30 module as binary sensors — event-driven over a serial device server such as a Moxa NPort. Name the inputs and pick device classes in the UI; door contacts, water sensors, alarm panel outputs or pump status land directly in Home Assistant. Requires a serial-to-Ethernet device server — the RD30 alone has only an RS-232 port.

Works with: AK MODUL-BUS RD30 via a serial device server (Moxa NPort 5110 tested)
GitHub Add to Marketplace

How to install

All integrations are installed via the Home Assistant Marketplace (built into Home Assistant since 2026.11, formerly HACS). Eleven of them are listed in the Marketplace default catalog, the others are added as custom repositories:

  1. Integrations marked In Marketplace default catalog: open Settings → Marketplace in your Home Assistant, search for the integration name and download it. For the others, click Add to Marketplace on the card above — it opens your own Home Assistant and adds the repository automatically (or add it manually in the Marketplace as a custom repository, type Integration).
  2. Click Download in the Marketplace (if not done yet) and restart Home Assistant.
  3. Go to Settings → Devices & services → Add integration and search for the integration name. A guided setup wizard does the rest.

Every integration speaks German, English, French and Italian and comes with a detailed README on GitHub.
